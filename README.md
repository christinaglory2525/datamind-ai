# 🤖 DataMind AI

## AI-Powered Conversational Database Intelligence Agent

DataMind AI is an AI-powered database assistant that allows users to ask questions about an e-commerce database using natural language.

Instead of writing SQL manually, users can simply ask questions such as:

> What are the top 5 products by revenue?

DataMind AI understands the question, generates the required SQL query, executes it against the database, explains the result, and provides a visualization.

## 🚀 Features

- Natural-language database queries
- AI-powered SQL generation using Google Gemini
- SQLite database integration
- Read-only SQL query generation
- Automatic query execution
- AI-generated explanations
- Data visualization
- Database ER diagram generation
- FastAPI backend
- Interactive web frontend

## 🛠️ Technology Stack
